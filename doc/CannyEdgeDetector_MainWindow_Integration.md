## 📖 使用说明

### 1. 打开功能
启动应用后，在左侧菜单找到：
```
图像处理
  └─ Canny边缘检测
```

### 2. 加载图像
- **方法1**: 点击"加载图像"按钮，选择图像文件
- **方法2**: 点击"生成测试图像"，使用预设的几何图形

### 3. 调整参数
- **快速方式**: 点击参数预设按钮（推荐从"通用场景"开始）
- **手动调整**: 使用滑块调整各个参数

### 4. 执行检测
- 点击"执行边缘检测"按钮
- 等待检测完成（通常几百毫秒）
- 查看右侧可视化结果和左侧统计信息

### 5. 优化结果
- 如果边缘太少：降低阈值
- 如果噪声太多：增大sigma，提高阈值
- 如果曲线太碎：降低最小曲线长度
- 如果结果太密：增大最小曲线长度

## ⚙️ 参数调优指南

### Sigma (高斯滤波)
- **0**: 不滤波，保留所有细节，但可能有噪声
- **0.5-1.0**: 轻度滤波，适合清晰图像
- **1.0-2.0**: 中度滤波，通用场景（推荐）
- **2.0-3.0**: 强滤波，适合噪声图像

### High Threshold (高阈值)
- **10-20**: 低阈值，检测更多边缘（可能有噪声）
- **20-40**: 中等阈值，平衡检测（推荐）
- **40-60**: 高阈值，只检测强边缘
- **60+**: 非常高，只保留最强边缘

### Low Threshold (低阈值)
- 通常设为高阈值的 **1/2** 到 **1/3**
- 过低：可能连接过多噪声
- 过高：边缘可能不连续

### Min Curve Length (最小曲线长度)
- **1-5**: 保留所有小细节
- **10-20**: 过滤短边缘（推荐）
- **20+**: 只保留长曲线

## 🐛 故障排除

### 问题1: 加载图像失败
- 确保图像格式支持（JPG, PNG, BMP, TIF）
- 检查文件路径是否正确
- 确认OpenCvSharp依赖已安装

### 问题2: 没有检测到边缘
- 降低高阈值和低阈值
- 检查图像是否有明显边缘
- 尝试生成测试图像验证功能

### 问题3: 检测到太多噪声
- 增大sigma进行更强的滤波
- 提高高阈值和低阈值
- 增大最小曲线长度

### 问题4: 可视化结果不正确
- 检查是否正确反转了Y轴
- 确认ScottPlot版本兼容
- 查看是否有异常信息
